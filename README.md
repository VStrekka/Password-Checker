# Password Strength Checker
A Python based project that evaluates the strength of a user's password based on certain security requirements

The Password Strength Checker analyzes a password and checks whether it is strong enough by checking if it meets certain rules. The program provides feedback to the user about which requirements their passwords meet and/or is missing from the password which can help users understand how to create a stronger/secure password. 

Features:
- Checks minimum password length
- Checks for uppercase letters
- Checks for numbers in password
- Checks for symbols
- Provides feedback if password is missing anything or if it password is strong enough
